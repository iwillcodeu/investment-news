# AI 单条新闻摘要（悬停图标 + 弹层）

日期：2026-08-27  
状态：已确认设计，待实现计划  

## 背景

看板已有赛道级「AI 今日要点」。用户希望对**单条新闻**按需深入：悬停出现 AI 图标，点击后由服务端抓取该链接正文，用项目配置的大模型（`llm.config.json`）生成中文摘要，并以小弹层展示。

## 目标

- 悬停新闻行显示 AI 摘要入口；点击后弹层展示摘要。
- 使用现有 LLM 接入（`scripts/llm.py` + `llm.config.json`），不新增第三方依赖。
- 默认会话缓存；弹层内可「重新生成」。
- 兼容根路径与反向代理子路径（如 `/dailynews/`）。

## 非目标

- 不把摘要写入 `data.js` / 磁盘。
- 不做跨标签、跨设备持久缓存。
- 不解决全部反爬站点（403/强 JS 渲染页允许失败并提示）。
- 不构成投资建议；提示语保持现有产品口径。

## 决策摘要

| 项 | 选择 |
|---|---|
| 展示 | 居中小弹层（遮罩 + 卡片） |
| 缓存 | `sessionStorage`，关标签即清 |
| 再生成 | 弹层内「重新生成」跳过本地缓存再请求 |
| 架构 | `POST api/summarize` 服务端抓页 + 抽正文 + LLM |

## 交互

1. 新闻行悬停（或键盘焦点）时，在标题旁 / meta 区显示小号 AI 图标按钮；默认桌面隐藏，hover/focus 显示。
2. 触控设备：图标常显或行内常驻，避免纯 hover 不可用。
3. 点击图标：打开弹层。标题优先用该条中文标题（`zh`），否则原文标题。
4. 打开时：
   - 若 `sessionStorage` 已有该 `url` 的成功摘要 → 直接展示；
   - 否则显示加载态，并 `POST api/summarize`。
5. 弹层操作：「重新生成」「关闭」；Esc / 点击遮罩关闭。
6. 摘要文风：中文，约 3–6 句要点式，客观陈述，不写投资建议。

## 前端缓存约定

- Key：`invnews:summary:` + 规范化后的文章 `url`（字符串原样即可，不做复杂规范化以外的解码差异处理）。
- Value：JSON `{ "summary": "...", "title": "...", "at": <epoch_ms> }`。
- 仅缓存 `ok: true` 的成功结果；错误不写入。
- 「重新生成」：先清该 key（或带 `force` 忽略读取），再请求；成功后覆盖写入。
- 同一 `url` 并发点击：前端 in-flight Map 去重，共用一次请求。

## API

### `POST api/summarize`

相对路径，与现有 `api/refresh` 一致，兼容子路径反代。

**请求 JSON**

```json
{
  "url": "https://example.com/article",
  "title": "可选，用于提示模型",
  "force": false
}
```

- `force`：前端「重新生成」时传 `true`。服务端无会话缓存；该字段预留/便于日志，服务端每次均重新抓取与生成。

**成功响应** `200`

```json
{
  "ok": true,
  "summary": "……中文摘要……",
  "title": "可选回显"
}
```

**失败响应** `200` 或 `4xx/5xx`（实现可选；前端以 `ok` 为准）

```json
{
  "ok": false,
  "error": "人类可读原因"
}
```

## 后端流程

在 `server.py`（或抽到 `scripts/summarize.py` 再由 handler 调用）中：

1. **校验 URL**：仅 `http`/`https`；拒绝非 URL、空串；拒绝明显内网/元数据地址（如 `127.0.0.1`、`localhost`、`10.*`、`192.168.*`、`169.254.*`、`::1`），降低 SSRF 风险。
2. **抓取**：标准库 `urllib`，超时约 15–20s，设置常见浏览器 User-Agent；限制响应体大小（如 2MB）。
3. **抽正文**：去 `script`/`style`/`noscript`；优先 `<article>` / `<main>` / 常见正文容器，否则 body；剥标签得纯文本；空白折叠；截断约 8–12k 字符。
4. **过短/空**：不调用 LLM，返回明确错误（如「无法从该页提取正文」）。
5. **LLM**：`llm.load_config` + `llm.call`；system/user 提示要求中文要点摘要、不编造、不给投资建议；传入标题（若有）+ 正文截断。
6. **返回** JSON；摘要中的 HTML 特殊字符由前端 `esc` 后插入 DOM（文本节点或转义 HTML），防 XSS。

保持**纯标准库**，与现有工程一致。

## 错误处理

| 情况 | 行为 |
|---|---|
| 超时 / HTTP 错误 / 非 HTML | 弹层显示简短错误；不写缓存；可「重新生成」 |
| 正文过短/空 | 提示无法提取；可不调或明确未调模型 |
| LLM 失败 | 显示错误；不覆盖已有成功缓存 |
| 非法 URL / SSRF 拒绝 | 直接错误，不发起外连 |

## 文件改动（预期）

- `index.html`：悬停图标、弹层 UI、sessionStorage、调用 `api/summarize`
- `server.py`：`POST` 路由处理 summarize（可委托脚本）
- `scripts/summarize.py`（可选新建）：抓取 + 抽正文 + LLM，便于单测/CLI
- 不改 `data.js` schema；`llm.config.json` 无需新字段

## 部署注意

- 已部署的 pmo `/dailynews/` 反代需把 `api/summarize` 一并转到 8793（若现为整前缀 `/dailynews/` → `/`，则已覆盖，无需改 nginx）。
- 外网部署时该接口会消耗模型额度并出站抓页；保持与 `api/refresh` 同级的暴露面认知。

## 验收标准

1. 悬停新闻行可见 AI 图标；点击出现弹层。
2. 首次生成后关弹层再开，不重复请求（同标签会话内）。
3. 「重新生成」会再次请求并更新展示与缓存。
4. 配置的 `api` / `claude-cli` 均可被 `llm.py` 使用。
5. 非法 URL、抓取失败、正文为空时有可读错误，页面不崩。
6. 在 `/dailynews/` 子路径下相对 `api/summarize` 可用。
